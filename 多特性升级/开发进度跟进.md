## 2. 已实现能力

- 新增升级项：遁地 / 原地起飞 / 无冷却 / 随机推进；与空中冲刺同一升级槽模型。
- 能力启用仅看护腿已安装升级项；旧 `boostermod-features.json` 不再影响玩法。
- `/boostermod feature` 命令已移除。
- 遁地：已装升级且 `pitch >= 60°` 时触发；未朝下回落到原地起飞或普通推进。
- 升级槽禁止同类型重复放入。
- 升级项临时 UI：附魔书贴图 + 附魔光效 + 能力说明 tooltip（非附魔系统）。
- 四件主题合成配方已加入数据包。

## 4. 已知偏差 / 限制

1. **正式贴图未做**：升级项暂用原版附魔书外观，后续只换 model 贴图即可。
2. **无升级 HUD**：按方案本期不做已启用升级的 HUD/聊天提示。
3. **随机 impulse 硬编码**：区间仍为 `[0.1, 1.0)`，无可配置入口。
4. **游戏内验收未跑**：手感、朝下阈值、破坏边界等需实机确认。
