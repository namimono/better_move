# 破壁推进

Status: ready-for-agent

## Problem Statement

当前玩家触发推进后，一旦撞上水平墙体，本次推进会立即结束，玩家的速度和冲击感都被墙面截断。玩家希望把突破墙体做成一个可选的升级能力：安装升级项后，推进可以沿实际飞行路径持续破坏阻挡方块并保持前进，以生命值作为长距离破壁的代价。该能力需要优先交付稳定、震撼的核心体验，不在首版扩张到多人领地兼容或复杂升级组合。

## Solution

新增“破壁升级项”。玩家安装后，推进撞上正常可破坏方块会进入“破壁推进”：系统按玩家碰撞体实际扫过的范围清除约 1 格宽、2 格高的通道，产生不受工具条件限制的基础掉落，并维持玩家进入墙体时的前向速度。

破壁推进不设置固定持续时间。玩家留在连续墙体内时，每 10 tick 承受一次固定的半颗心伤害；生命值充足便可持续突破很长距离。飞出墙体后停止保速和扣血，恢复正常惯性；同一次推进仍有明显前向速度且尚未落地时，再撞入另一堵墙可以重新进入破壁推进。遇到不可破坏方块、玩家死亡、落地或失去有效推进状态时结束。

创造模式保留相同节奏的受伤动画、音效和屏幕反馈，但不实际降低生命值。与过载蓄力组合时：破壁期间进入墙体即触发真实过载爆炸，持续清方按生命代价同节奏再次爆炸，离开墙段后 re-arm，撞上不可破坏方块时再炸一次并结束。

## User Stories

1. As a 玩家, I want 将破壁升级项安装到推进器护腿的升级槽, so that 我可以按现有升级系统选择是否启用破壁推进
2. As a 玩家, I want 用钻石镐、三份火药和一份红石合成破壁升级项, so that 这个强力能力具有与效果相称的获取成本
3. As a 玩家, I want 在创造物品栏和升级界面中识别破壁升级项, so that 我可以正常获取、查看和安装它
4. As a 玩家, I want 未安装破壁升级项时撞墙仍按现有规则停止推进, so that 新能力不会改变所有推进器的默认行为
5. As a 玩家, I want 安装破壁升级项后撞上正常可破坏方块仍继续前进, so that 墙体不再立即截停推进
6. As a 玩家, I want 破壁推进只破坏身体实际飞行路径扫过的方块, so that 能清出可通行通道而不会无故拆除侧墙
7. As a 玩家, I want 直线破壁形成约 1 格宽、2 格高的通道, so that 玩家碰撞体能够通过且普通破坏范围保持克制
8. As a 玩家, I want 斜向破壁按碰撞体真实扫过范围清方, so that 斜飞时不会因通道计算过窄而卡进方块
9. As a 玩家, I want 破壁方向跟随实际飞行路径而不是视线, so that 穿墙时转头不会拆掉没有飞向的侧墙
10. As a 玩家, I want 被破壁推进移除的方块产生基础掉落, so that 突破墙体不会吞掉沿途资源
11. As a 玩家, I want 方块掉落不要求玩家手持正确工具, so that 石头、矿石等阻挡物被突破后仍能产生其无附魔基础掉落
12. As a 玩家, I want 破壁掉落不应用精准采集或时运, so that 升级项不会继承或虚构工具附魔收益
13. As a 玩家, I want 基岩等原版不可破坏方块保持不变并终止推进, so that 破壁升级项不破坏 Minecraft 的硬边界
14. As a 玩家, I want 进入连续墙体后保持进入时的前向速度, so that 方块碰撞不会逐格耗尽推进动量
15. As a 玩家, I want 连续墙体内的破壁推进没有固定时间上限, so that 血量充足时可以完成震撼的长距离突破
16. As a 玩家, I want 飞出墙体后停止破壁保速并恢复正常惯性, so that 升级项不会在空中提供无限巡航
17. As a 玩家, I want 同一次推进穿出一堵墙后仍可撞入并突破第二堵墙, so that 分离的障碍不会意外绕过升级能力
18. As a 玩家, I want 落地或前向推进速度基本耗尽后结束本次破壁资格, so that 普通移动不会残留破壁能力
19. As a 生存或冒险玩家, I want 首次进入墙体并在持续破壁期间按每 10 tick 半颗心的节奏受伤, so that 长距离破壁有持续且可理解的生命代价
20. As a 生存或冒险玩家, I want 破壁伤害固定且不被护甲、抗性效果或受伤无敌帧减免, so that 相同破壁时长始终对应相同代价
21. As a 残血玩家, I want 破壁伤害可以致死并在死亡时立即停止推进和破坏, so that 强行破壁具有真实风险且不会留下死亡后的运动状态
22. As a 创造模式玩家, I want 破壁时看到和听到与生存模式同节奏的受伤反馈但不实际失去生命值, so that 我能感知能力代价而不会留下切回生存后的残血状态
23. As a 玩家, I want 在空气中飞行时不累计破壁伤害, so that 生命代价只来自实际突破墙体
24. As a 玩家, I want 离开墙体后重置连续破壁伤害计时, so that 每一段独立墙体都有清晰的伤害生命周期
25. As a 玩家, I want 破壁推进不额外消耗推进器耐久或饥饿值, so that 专属代价集中在生命值而不是三重资源惩罚
26. As a 玩家, I want 普通破壁推进撞到实体时不自动造成碰撞伤害, so that 伤害来源不会与推进破击的领域边界冲突
27. As a 玩家, I want 卸下推进器或破壁升级项、死亡或其他现有推进取消条件立即清除破壁状态, so that 能力始终由当前有效装备和推进生命周期决定
28. As a 使用饰品槽的玩家, I want 通过 Trinkets 穿戴的推进器同样支持破壁升级项, so that 两种既有装备入口行为一致
29. As a 玩家, I want 武装村民继续忽略破壁升级项, so that 玩家专属新能力不会扩张村民推进范围

## Implementation Decisions

1. **升级项身份**：新增破壁升级项类型及对应物品，接入现有升级槽、序列化、去重、物品栏展示、升级界面、双语名称与提示文本。与其他升级项一样，同类型不可重复安装。
2. **配方**：使用现有升级项的三行有序合成结构；中心为钻石镐，上方及左右为三份火药，下方为一份红石。
3. **装备入口**：继续通过统一的推进器装备查询识别护腿槽和 Trinkets 饰品槽，不新增独立穿戴路径。
4. **服务端权威**：破壁判定、方块破坏、掉落、速度维护、伤害和生命周期全部由服务端执行。玩家仍通过现有推进请求发起能力，不新增客户端到服务端的破壁请求协议。
5. **升级检测**：成功发起推进时识别当前推进器是否安装破壁升级项，并在推进生命周期中持续验证装备仍有效。未安装时保留普通非过载推进碰到水平墙体即结束的现有行为。
6. **运动状态**：玩家推进运动模块扩展破壁资格与墙内状态。破壁资格可跨越空气间隔保留，直至玩家落地、原推进方向的有效速度基本耗尽、死亡、失去有效装备或触发现有取消条件。
7. **进入与离开墙体**：当实际运动扫掠范围首次遇到可破坏阻挡物时进入破壁推进，并记录进入墙体时的前向速度。只要仍在连续破坏阻挡物，就补偿方块碰撞导致的速度损失；离开墙体立即停止补偿并恢复原版惯性。
8. **无固定上限**：破壁推进不设置按 tick 或距离计算的硬上限。生存与冒险玩家受生命值约束；创造模式可以持续穿过连续墙体，直到其他结束条件出现。
9. **扫掠范围**：破坏候选来自玩家碰撞体沿本 tick 实际速度方向的扫掠体积，而不是单条视线射线。只清理确保玩家身体通过所需的方块；直线情况下目标通道约为 1 格宽、2 格高，斜向时允许自然覆盖边缘方块。
10. **高速安全**：扫掠必须覆盖一个 tick 内完整位移，不能只检查玩家当前位置相邻方块，以避免高初速度或平衡参数调整后穿漏方块、卡墙或服务端位置回弹。
11. **可破坏边界**：空气和不构成阻挡的状态不需要移除；正常可破坏方块可以清除；破坏速度为负等原版不可破坏方块不可清除，并终止当前推进。
12. **掉落语义**：所有由核心破壁通道移除的正常可破坏方块生成其无附魔基础掉落，不要求玩家实际持有正确工具，也不应用精准采集、时运或玩家手持物属性。方块更新和方块实体的原版清理语义应正常执行。
13. **伤害节奏**：首次成功进入破壁推进时立即产生一次半颗心伤害；持续破坏期间每累计 10 tick 再产生一次。只有实际处于破壁推进的 tick 计入；离墙后清零，重新进入另一堵墙时重新开始。
14. **真实固定伤害**：生存和冒险模式每次直接减少 1 点生命值，不被护甲、抗性效果或常规受伤无敌帧吞掉，可以致死。死亡后同 tick 或最早安全时机清理运动与破壁状态。
15. **创造反馈**：创造模式不改变真实生命值，但服务端仍按同一节奏触发对该玩家可见、可听的受伤动画、音效和屏幕受击反馈。不得通过先扣血再回血制造切换模式后的状态风险。
16. **资源结算**：一次推进继续只使用现有耐久、饥饿和冷却结算；破坏方块数量与破壁持续时间不增加推进器耐久或饥饿消耗。
17. **实体交互**：普通破壁推进不新增身体碰撞伤害。推进破击仍只由主动近战命中触发；实体不作为破壁通道的可破坏对象。
18. **装备与生命周期**：卸下推进器、移除破壁升级项、切换世界、断线、死亡或其他既有推进取消条件均清除破壁状态、速度补偿和计时器，避免跨生命周期残留。
19. **客户端内容**：新增升级项物品栏图标、物品模型、简体中文和英文名称及提示文本。首版不新增专用 HUD、蓄力条、镜头系统或新的穿戴外观。
20. **既有系统兼容**：破壁升级项只影响玩家推进。武装村民继续忽略所有升级项；遁地仍使用既有向下破方路径；推进破击、Hyper 保持现状。与过载蓄力组合时启用破壁期间持续真实过载爆炸（见 Solution）；无破壁时过载仍为首次撞击一次爆炸后结束。
21. **领域用词**：规格与实现使用 `CONTEXT.md` 中的“破壁推进”和“破壁升级项”，避免用“穿墙”“撞墙”或“钻墙”指代正式能力。

## Testing Decisions

1. 测试验证外部可观察的游戏行为，不断言运动模块的私有集合、内部计时字段、方块枚举顺序或具体实现类拆分。
2. 主测试接口是现有 **Fabric 服务端 GameTest 世界场景**。测试在真实服务端世界中生成并装备可受伤的模拟玩家，通过现有玩家推进入口发起推进，再推进服务器 tick。
3. GameTest 从公开世界和实体状态观察玩家位置、速度、生命值、方块状态、掉落物实体及推进生命周期；不新增测试专用业务 API。
4. GameTest 至少覆盖：未安装升级项撞墙仍停止；安装后穿过足够长的可破坏墙；直线形成约 1×2 通道；斜向扫掠不让玩家卡入剩余方块；侧看不破坏实际路径外墙体。
5. GameTest 至少覆盖：石头和矿石等需要正确工具的方块仍产生无附魔基础掉落；不可破坏方块不被移除并终止推进；高速推进不会跳过路径中的阻挡方块。
6. GameTest 至少覆盖：进入墙体保持前向速度；连续墙体内不因固定时限停止；飞出墙体恢复正常惯性；空气间隔不扣血；同一次推进可以进入第二堵墙；落地或速度耗尽后不再破壁。
7. GameTest 至少覆盖：首次破壁及此后每 10 tick 固定扣半颗心；护甲、抗性和无敌帧不改变数值；伤害可致死并清理状态；破壁不增加耐久或饥饿消耗。
8. GameTest 至少覆盖：创造模式生命值保持不变且产生受伤反馈事件；生存和冒险模式真实扣血；实体碰撞不产生额外伤害。
9. GameTest 至少覆盖：护腿槽与可用的统一装备查询路径都能识别升级项；卸装、移除升级项、死亡和取消推进后不残留破壁状态。
10. 测试实现参考仓库现有的服务端 GameTest 场景、长走廊构造和 `VulnerableFakePlayer`，尤其是已有的推进边界测试；纯规则若自然形成，可补充 JUnit 测试，但不能替代主 GameTest 验收。
11. 物品注册、配方、模型和语言资源由构建资源处理及至少一次人工创造物品栏冒烟检查验证；不要求像素级截图测试。

## Out of Scope

- 为持续过载爆炸单独配置半径/自伤/节奏（当前复用既有过载爆炸参数 + 破壁生命代价间隔）
- 领地、出生点保护或其他多人服务器保护模组兼容
- 针对特殊模组方块、多方块结构或自定义方块实体的专用兼容
- 为掉落物增加自动合并、立即清理、传送给玩家或独立数量上限
- 按方块硬度、破坏数量或推进器等级改变破壁速度、伤害或掉落
- 额外耐久、饥饿、燃料、冷却或其他破壁资源系统
- 破壁碰撞伤害、自动攻击或对推进破击规则的扩展
- 破壁专用 HUD、计量条、配置命令、服务器配置项或玩家开关
- 武装村民使用破壁升级项
- 对遁地、Hyper、随机推进、垂直起飞、空中推进或无冷却升级项进行玩法重做

## Further Notes

- 本规格来自已结束并确认的 `grill-with-docs` 会话。过载+破壁持续爆炸已实现：进入墙段炸一次、每 `COST_INTERVAL_TICKS` 清方再炸、空气间隔 re-arm、不可破坏边界终炸。
- 普通 Minecraft 掉落物在已加载并持续 tick 的区块中约 5 分钟后消失；玩家飞远导致区块卸载不会立即删除掉落物。长距离破壁可能留下大量掉落实体，这是当前明确接受的性能与资源代价。
- 当前玩家推进由客户端请求、服务端验证并由服务端运动 tick 驱动；普通非过载推进会在水平碰撞时立即结束。首版应在服务端运动路径中增加破壁分支，而不是建立第二套推进协议。
- 现有遁地能力已经具有服务端检查不可破坏方块、破坏方块和移动玩家的实现经验，但破壁推进需要完整高速扫掠、连续状态和速度维护，不能直接等同于固定深度的逐格向下传送。
- 现有 GameTest 基础设施、长走廊场景和可受伤模拟玩家可直接作为主验收 seam，避免为了测试暴露新的生产接口。
