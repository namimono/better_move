# 04 — 落实生命代价与装备生命周期

**What to build:** 生存和冒险玩家只在实际破壁期间承担固定且可致死的生命代价，破壁资格始终随当前装备和推进生命周期变化，并在所有结束条件下可靠清理。

**Blocked by:** 03 — 完善破壁路径与连续运动.

**Status:** ready-for-human

- [x] 生存和冒险玩家首次成功进入一段墙体时立即失去 1 点生命值，持续破壁期间每累计 10 tick 再失去 1 点生命值。
- [x] 只有实际破坏阻挡物的 tick 计入伤害节奏；空气中不累计，离墙后计时清零，进入下一堵墙时重新立即结算。
- [x] 固定生命损失不被护甲、抗性效果或常规受伤无敌帧减少或吞掉。
- [x] 破壁伤害可以致死，死亡后不再移动或破坏方块，也不残留速度补偿及伤害计时。
- [x] 推进过程中卸下推进器或移除破壁升级项会立即失去破壁资格并清除相关状态。
- [x] 断线、切换世界以及其他既有推进取消条件都会清除破壁状态。
- [x] 通过护腿槽和可用的 Trinkets 饰品槽穿戴推进器时，统一装备查询均能启用并持续验证破壁升级项。
- [x] 武装村民装备含破壁升级项的推进器时，其村民推进和碰撞边界保持原有行为。
- [x] GameTest 覆盖伤害节奏、减伤绕过、致死清理、装备移除、取消条件和两种装备入口。
