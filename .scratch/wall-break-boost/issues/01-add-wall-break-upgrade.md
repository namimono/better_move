# 01 — 新增可获取、可安装的破壁升级项

**What to build:** 玩家可以通过现有内容与升级系统获取、识别、安装、保存和移除破壁升级项，为后续破壁推进能力提供稳定且完整的玩家入口。

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [x] 破壁升级项可以用钻石镐、三份火药和一份红石按规格中的有序结构合成。
- [x] 破壁升级项出现在创造物品栏，并具有可识别的物品栏图标、物品模型、简体中文和英文名称及提示文本。
- [x] 破壁升级项可以放入推进器护腿的有效升级槽，关闭并重新打开升级界面后仍正确显示。
- [x] 安装状态经过物品保存、加载和装备流转后仍能被现有升级查询识别。
- [x] 同一件推进器护腿不能安装两个破壁升级项，移除后能力标记同步消失。
- [ ] 构建和资源处理通过，并完成人工创造物品栏及升级界面冒烟检查。
