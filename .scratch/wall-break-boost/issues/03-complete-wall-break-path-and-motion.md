# 03 — 完善破壁路径与连续运动

**What to build:** 破壁推进沿玩家碰撞体的实际高速或斜向飞行路径稳定清方，并在连续墙体和分离墙体之间维持符合规格的动量与资格生命周期。

**Blocked by:** 02 — 打通单堵直线墙体.

**Status:** ready-for-agent

- [ ] 每个服务端 tick 的破坏候选覆盖玩家碰撞体沿完整实际位移扫过的范围，高速推进不会跳过路径中的阻挡方块或造成位置回弹。
- [ ] 斜向破壁自然覆盖碰撞体需要经过的边缘方块，不会因通道过窄把玩家卡入剩余方块。
- [ ] 破坏方向跟随实际飞行速度而不是玩家视线，破壁期间转头不会拆除飞行路径外的侧墙。
- [ ] 首次进入墙体时记录的前向速度在连续破壁期间得到维持，不会因逐格方块碰撞衰减，也不受固定 tick 或距离上限限制。
- [ ] 飞出墙体后立即停止速度补偿并恢复正常惯性，空气阶段不获得无限巡航。
- [ ] 同一次推进仍有明显原方向速度且尚未落地时，可以在空气间隔后再次进入并突破另一堵墙。
- [ ] 落地或原推进方向的有效速度基本耗尽后，普通移动不再保留破壁资格。
- [ ] GameTest 覆盖高速、斜向、侧看、长墙、出墙和同次推进进入第二堵墙的外部可观察行为。
