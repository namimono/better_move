# 05 — 补齐创造反馈与玩法边界

**What to build:** 创造模式玩家能够感知与生存模式相同的破壁代价节奏但不损失生命，同时完整锁定破壁推进与现有资源、实体伤害和升级能力之间的边界。

**Blocked by:** 04 — 落实生命代价与装备生命周期.

**Status:** ready-for-agent

- [ ] 创造模式玩家在首次进入墙体及此后每 10 个持续破壁 tick 收到可见、可听的受伤反馈，但真实生命值始终不变。
- [ ] 创造反馈不通过先扣血再回血实现，切换游戏模式后不会留下错误生命状态。
- [ ] 一次推进仍只结算现有耐久、饥饿和冷却成本；破坏方块数量和破壁时长不会增加耐久或饥饿消耗。
- [ ] 普通破壁推进碰到实体时不会自动造成身体碰撞伤害，推进破击仍只由主动近战命中触发。
- [ ] 破壁升级项不会改变遁地、Hyper、普通过载蓄力及其他未在规格中声明组合行为的既有规则。
- [ ] 服务端 GameTest 覆盖创造反馈、生命值不变、资源结算和实体无碰撞伤害，并通过完整构建与既有测试回归。
- [ ] 人工冒烟验证核心破壁体验稳定，且未引入破壁专用 HUD、持续过载爆炸或其他规格外能力。
