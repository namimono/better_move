# Edge-case matrix for charge lifecycle

Type: grilling  
Status: resolved  
Blocked by: 01, 05  

## Question

钉死蓄力生命周期在边界情境下的行为表（每行：情境 → 是否可蓄力 / 是否取消 / 是否可释放 / 是否结算资源）：

至少覆盖：

- 创造 / 旁观 / 死亡 / 睡觉
- 游泳、潜水、岩浆中、鞘翅滑翔
- 已在推进中；冷却中；饱食不足
- 蓄力中打开容器 / 升级 UI / 切换维度 / 卸下护腿或 Trinket
- 空中无空中冲刺升级时的蓄力与释放
- 客户端卡顿导致松手包迟到 vs 服务端 5s 自动释放竞态（可引用 research 结论）

输出一张可贴进实现方案的矩阵；与 map Notes 冲突时以 Notes 为准并记录例外。

## Answer

与 [蓄力与过载升级 map](../map.md) Notes 一致；与 [Research: hold-to-charge networking on Fabric 1.21](05-research-charge-networking.md) 服务端时钟模型一致。用词：蓄力 / 释放 / 强制释放 / 取消蓄力。

**全局规则**

- 取消蓄力：不推进、不写冷却、不扣饥饿/耐久。
- 资源：仅 **成功释放并起飞** 后结算（创造 `instabuild` 跟现有推进）。
- 释放失败（校验不过）：结束会话、不推进、不结算。
- 有过载蓄力时：无会话的 fire 包 **忽略**，不走点按瞬发旁路。

### 矩阵

| 情境 | 开始蓄力 | 蓄力中进入该态 | 释放 | 资源 |
|------|----------|----------------|------|------|
| 生存/冒险（基准） | 是* | — | 是* | 成功才结算 |
| 创造 | 是 | 保持 | 是 | 跟现有推进 |
| 旁观 | 否 | 取消蓄力 | 否 | 无 |
| 死亡 | 否 | 取消蓄力 | 否 | 无 |
| 睡觉 | 否 | 取消蓄力 | 否 | 无 |
| 游泳 / 潜水 / 岩浆 / 鞘翅 | 是* | 保持 | 是*（现有推进校验） | 成功才结算 |
| 已在推进中 | 否（忽略） | — | 否 | 无 |
| 冷却中（无「无冷却」） | 否 | 若中途进 CD → 取消蓄力 | 否 | 无 |
| 冷却中（有无冷却） | 是 | — | 是* | 成功释放；不写 CD |
| 饱食不足（非创造，&lt; 现有阈值） | 否 | 取消蓄力 | 否 | 无 |
| 开任意容器 / GUI / 升级 UI | — | 取消蓄力 | — | 无 |
| 卸护腿 / Trinket / 过载蓄力升级项 | — | 取消蓄力 | — | 无 |
| 切换维度 / 同维传送 | — | 取消蓄力 | — | 无 |
| 空中且无空中冲刺 | **允许** | 保持 | 仍不满足 → 失败结束会话 | 不结算 |
| 服务端强制释放（过载窗口耗尽） | — | — | 释放（满过载） | 成功则结算 |
| 强制释放或取消后迟到松手包 | — | — | **忽略** | 无 |
| 同 tick：取消 vs 强制释放 | — | — | **取消优先** | 无 |

\*仍受：已装备推进器、已装过载蓄力、非推进中、非冷却（除非无冷却）、饱食/创造等行约束。

### 环境

不新增「在水/岩浆/鞘翅中禁止蓄力」的特判；液体与过载爆炸关系见 map Notes（液体不触发过载爆炸）。

### 网络竞态（摘录）

- 权威：服务端 `ChargeSession` + `startTick`；满 tick **强制释放**。
- 迟到 RELEASE：会话已清 → 忽略。
- 客户端 HUD 与服务端不一致时以服务端为准；可选 S2C 清状态（实现可选，非本票必选）。
