# Domain vocabulary for charge and overload

Type: grilling  
Status: resolved  
Blocked by:  

## Question

为「蓄力 / 过载」升级钉死 `CONTEXT.md` 可用的领域词表：至少包括蓄力、过载、蓄力时长、过载窗口、自动释放、过载爆炸、取消蓄力；并与现有词（推进、升级项、遁地、推进破击、Hyper）划清边界，避免同义混用。

Charting 已锁定的行为约束见 [蓄力与过载升级 map](../map.md) Notes，本票只定 **叫什么**，不重开玩法。

## Answer

词表已写入仓库根目录 [`CONTEXT.md`](../../../CONTEXT.md)。摘要：

| 规范词 | 要点 |
|---|---|
| **升级项** | 槽位能力物品；避免「模块/插件」 |
| **推进** | 一次定向冲量移动；避免「冲刺/boost」 |
| **过载蓄力** | 本功能升级项产品名 |
| **蓄力** | 按住推进键、尚未释放的准备态 |
| **过载** | 满蓄后危险段；距离封顶，可过载爆炸 |
| **蓄力时长** | 蓄力阶段可持续多久 |
| **过载窗口** | 过载后至强制释放前的可按住时段 |
| **释放** | 结束蓄力并触发推进（含松手） |
| **强制释放** | 过载窗口耗尽后的系统释放（**不用**「自动释放」） |
| **过载爆炸** | 过载推进首次碰固体/实体的一次爆炸 |
| **取消蓄力** | 中止且不推进；免费 |
| **遁地** | 朝下破方下潜的推进形态 |
| **推进破击** | 主动近战强化；≠ 过载爆炸 |
| **Hyper** | 起跳窗口推进强化技巧；≠ 过载、非升级项 |

**对既有票的校正**： [Upgrade item identity and craft](02-upgrade-item-identity.md) 的中文显示名由「蓄力升级项」改为 **过载蓄力**，与本词表对齐；英文 id `CHARGE`/`charge_upgrade` 可保留（代码 id 不必等于中文产品名）。
