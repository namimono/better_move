# 02 — 武装村民完成交战生命周期

**What to build:** 让装备齐全的武装村民在安全边界内锁定可攻击玩家、接管追击行为，并在目标或装备条件不再成立时可靠脱离追击、恢复原本的村民日程。武装状态始终由当前装备实时派生，不形成永久职业、阵营或所有权。

**Blocked by:** 01 — 村民拾取并保全武装装备

**Status:** ready-for-agent

- [ ] 仅当成年村民的护腿槽穿有本模组推进器且主手持有 `swords` 标签内的剑时，才实时判定为武装村民。
- [ ] 非和平难度下，未交战的武装村民从 32 格内当前可见的可攻击玩家中锁定最近者。
- [ ] 仅存活且处于生存或冒险模式、可被实体正常攻击的玩家具备目标资格；创造、旁观、死亡及其他不可攻击玩家被忽略。
- [ ] 装备投放者不获得所有权或友军豁免，各武装村民独立锁敌，不共享目标或传播敌对状态。
- [ ] 交战期间武装村民以追击为主要行为，工作、睡眠、社交、恐慌和交易等普通日程不会打断交战。
- [ ] 短暂失去目标视线时继续正常寻路追击，不会仅因一次遮挡立即脱离。
- [ ] 目标失效或与村民距离超过 48 格时立即脱离追击。
- [ ] 目标仍在 48 格内，但连续 200 tick 既不可见又无法接近时脱离追击，并可在之后重新参与锁敌。
- [ ] 和平难度下保留已有装备，但不锁敌或追击；从其他难度切换至和平后会停止现有交战。
- [ ] 推进器或剑损坏、移除或离开规定槽位后，村民立即退出武装状态并停止交战。
- [ ] 脱离追击后不再保留攻击目标，导航与普通职业、生活及交易行为能够恢复。
- [ ] GameTest 从公开实体状态和世界结果验证上述行为，不依赖 Brain 内存布局、注入点或控制器私有状态。
- [ ] 项目构建、现有测试及本 ticket 的 GameTest 全部通过。
