# 04 — 完善村民推进边界与装备生命周期

**What to build:** 补齐村民推进的全部触发、运动和生命周期边界，使非法环境不会发起推进，进行中的推进能在危险或失效条件出现时立即结束，并保证装备损坏、掉落、坠落伤害与玩家既有推进路径都保持规格要求。

**Blocked by:** 03 — 武装村民执行剑击与基础推进

**Status:** ready-for-agent

- [ ] 武装村民在空中、水中、熔岩中、乘坐载具或被拴住时不发起村民推进。
- [ ] 朝目标方向存在明显固体阻挡时不发起村民推进。
- [ ] 村民推进碰到固体障碍或进入水、熔岩时立即结束，不会卡入障碍或液体。
- [ ] 村民死亡、卸载、转换、失去推进器或进入其他非法生命周期状态时，进行中的村民推进立即结束且不残留运行状态。
- [ ] 推进器因发起推进耗尽耐久时立即重新计算武装状态，结束进行中的能力并停止攻击。
- [ ] 村民推进持续期间不累计坠落距离；推进结束后恢复原版坠落累计，高处继续坠落仍可能受到正常伤害。
- [ ] 推进器上的空中推进、无冷却、随机冲量、垂直起飞、遁地、推进破击和过载蓄力等升级项均不改变村民推进的触发、方向、距离、伤害或冷却。
- [ ] Hyper 及其他玩家专属技巧不会应用于村民推进。
- [ ] 装备损坏、移除或错槽后，交战、村民剑击与村民推进均立即停止；重新满足装备条件后可按正常规则重新锁敌。
- [ ] 武装村民死亡时推进器和剑仍必定原样掉落，包括当前耐久、附魔及推进器升级项数据。
- [ ] GameTest 覆盖所有禁止发起条件、固体和液体终止、装备损坏、能力清理、坠落规则、升级项隔离及完整掉落。
- [ ] 在服务端人工冒烟验收中，附近玩家能够听到基础推进世界音效并看到云雾轨迹，且客户端没有收到玩家专属推进反馈。
- [ ] 可重复运行的 GameTest、现有 JUnit 测试和完整项目构建全部通过，现有玩家推进、网络协议、HUD、镜头及升级项行为无回归。
