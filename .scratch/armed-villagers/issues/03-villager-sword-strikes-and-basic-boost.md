# 03 — 武装村民执行剑击与基础推进

**What to build:** 让交战中的武装村民形成完整、可观察的攻击循环：近距离使用村民剑击，中距离自主使用村民推进接近目标，远距离先寻路。推进期间仍能以普通节奏剑击，而推进和身体碰撞本身不成为伤害来源。

**Blocked by:** 02 — 武装村民完成交战生命周期

**Status:** ready-for-human

- [x] 武装村民在原版生物近战可达范围内执行村民剑击，使用 1 点基础攻击力并叠加主手剑的原版属性与附魔伤害修正。
- [x] 村民剑击每 20 tick 最多执行一次，只有成功命中才消耗剑 1 点耐久。
- [x] 村民剑击不触发玩家专属暴击、横扫、攻击蓄力或推进破击。
- [x] 目标不足 6 格时使用普通近战追击，超过 20 格时先寻路接近，不发起村民推进。
- [x] 交战中的武装村民在地面、目标可见、距离处于闭区间 6～20 格且前方无明显固体阻挡时自主发起村民推进。
- [x] 村民推进发起时根据目标当前位置计算一次方向，途中不持续追踪或修正到目标的新位置。
- [x] 村民推进使用所穿推进器等级的基础平衡参数，不依赖玩家按键、C2S 网络包、玩家冷却容器或村民食物库存。
- [x] 每次成功发起村民推进立即消耗推进器 1 点耐久，并为该村民记录 60 tick 服务端冷却；冷却内不重复发起，结束后可再次发起。
- [x] 村民推进期间仍按普通 20 tick 间隔进行村民剑击；进入近战范围后能够命中目标。
- [x] 村民推进、身体接触和运动碰撞本身不对目标造成额外伤害。
- [x] 发起推进时播放附近玩家可感知的基础推进世界音效，结束时产生云雾轨迹。
- [x] 村民推进不向任何玩家发送“自己推进”的 HUD、镜头、冷却或第一人称反馈。
- [x] GameTest 覆盖剑与附魔伤害、攻击间隔、两类装备耐久、三段距离行为、固定发起方向、推进期间剑击及无碰撞伤害。
- [x] 项目构建、现有测试及本 ticket 的 GameTest 全部通过，现有玩家推进行为保持不变。
