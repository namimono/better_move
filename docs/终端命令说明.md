# Booster Mod · 终端命令说明

> 更新日期：2026-07-24  
> 根命令：`/boostermod`  
> 实现：`com.boostermod.command.BoosterModCommand`  
> 权限：默认需要 **权限等级 2**（作弊 / OP 2+ / 服务端控制台）

本文只记录**当前仍可用**的命令。历史已移除的命令见文末。

---

## 1. 快速索引

| 分类 | 命令前缀 | 用途 |
|---|---|---|
| HUD | `/boostermod hud ...` | 热键栏右侧推进 HUD 总开关 |
| 屏幕震动 | `/boostermod shake ...` | 推进镜头震动开关 |
| 推进破击叠层 | `/boostermod strike stack ...` | 调试：锁定/解锁/查看攻击叠层 |
| 推进手感数值 | `/boostermod balance ...` | 分品质 impulse / 推力 / 持续 tick |

**键位（非命令）**：默认推进键 `Z`（可在控制设置 → Boostermod 中改）。

---

## 2. 通用说明

### 2.1 权限

```text
.requires(source -> source.hasPermission(2))
```

- 单人开启作弊或局域网允许作弊后可用。  
- 专用服务器需 OP 等级 ≥ 2，或在控制台直接执行。  
- 无权限时命令不出现在 Tab 补全中，或提示无权限。

### 2.2 玩家选择器（部分子命令）

`strike stack` 系列支持可选目标：

| 写法 | 含义 |
|---|---|
| 省略 `targets` | 对自己执行（控制台必须写目标） |
| `@s` / `@p` / `@a` / 玩家名 | 标准选择器 |

示例：

```mcfunction
/boostermod strike stack lock 28 @s
/boostermod strike stack status @a
```

### 2.3 配置落盘位置

服务器工作目录下 `config/`（本地 `run/` 开发环境同理）：

| 文件 | 关联命令 |
|---|---|
| `config/boostermod-hud.json` | `hud on/off` |
| `config/boostermod-shake.json` | `shake on/off` |
| `config/boostermod-booster-balance.json` | `balance set/reset/reload` |

叠层锁定**不落盘**，仅内存；断线或重进世界会丢失。

## 3. HUD 开关

控制所有在线玩家客户端是否绘制热键栏右侧推进面板（冷却 / 耐久 / 有破击时的叠层轨）。

| 命令 | 说明 |
|---|---|
| `/boostermod hud status` | 查询当前是否开启 |
| `/boostermod hud on` | 开启，并同步给在线玩家 |
| `/boostermod hud off` | 关闭，并同步给在线玩家 |

**备注**

- 关闭后不影响推进与破击逻辑，只隐藏 UI。  
- F1 隐藏 GUI 时面板同样不显示。  
- 设置会写入 `boostermod-hud.json`。

---

## 4. 屏幕震动开关

控制推进启动时的镜头震动 / 相关反馈是否生效。

| 命令 | 说明 |
|---|---|
| `/boostermod shake status` | 查询当前是否开启 |
| `/boostermod shake on` | 开启，并同步给在线玩家 |
| `/boostermod shake off` | 关闭，并同步给在线玩家 |

**备注**

- 写入 `boostermod-shake.json`。  
- 与 HUD 开关相互独立。

## 5. 推进破击 · 叠层调试

根路径：`/boostermod strike stack ...`

用于调试「推进破击」的**攻击力叠层**（加在 `ATTACK_DAMAGE` 上的临时加成），不是推进冷却条。

| 命令 | 说明 |
|---|---|
| `/boostermod strike stack status [targets]` | 查看叠层数值与是否锁定 |
| `/boostermod strike stack lock <value> [targets]` | 将叠层锁定为 `value`（≥ 0） |
| `/boostermod strike stack unlock [targets]` | 取消锁定 |

### 5.1 锁定行为（`lock`）

- 属性与 HUD 立刻变为指定叠层值。  
- **命中不再继续叠层**，**到期不会清零**。  
- 调试时可锁超过品质正常上限（例如铁档常规上限 28，可 `lock 40`）。  
- 直到 `unlock` 或玩家断线。

### 5.2 解锁行为（`unlock`）

- 去掉锁定标志。  
- 当前叠层**保留**，并按「命中时长」重新开始倒计时（到期后正常清零）。  
- 若当前为 0，则直接清零。

### 5.3 常用示例

```mcfunction
# 锁在接近铁档满层，方便测秒杀
/boostermod strike stack lock 28

# 锁在 0（清空并保持为 0，直到 unlock）
/boostermod strike stack lock 0

# 看自己状态
/boostermod strike stack status

# 取消锁定，让时间正常走
/boostermod strike stack unlock

# 给指定玩家
/boostermod strike stack lock 20 Steve
```

### 5.4 品质叠层参考（正常游玩上限，代码常量）

| 品质 | 叠层上限 `maxStack`（约） |
|---|---|
| 铜及以下 | 24 |
| 铁 | 28 |
| 金 | 32 |
| 钻石 | 36 |
| 下界合金 | 40 |

> 破击玩法本身还需要护腿装有 **推进破击升级项**；锁定命令改的是攻击力加成数值，不自动安装升级。

## 6. 推进手感数值（balance）

根路径：`/boostermod balance ...`  
调节各品质推进器的飞行参数，立即写盘并在后续推进中生效。

### 6.1 子命令一览

| 命令 | 说明 |
|---|---|
| `/boostermod balance show` | 列出全部品质当前数值 |
| `/boostermod balance show <tier>` | 只看某一品质 |
| `/boostermod balance set <tier> <field> <value>` | 修改某一字段（`value` ≥ 0） |
| `/boostermod balance reset` | 全部品质恢复默认 |
| `/boostermod balance reset <tier>` | 某一品质恢复默认 |
| `/boostermod balance reload` | 从配置文件重新加载（可手改 JSON 后 reload） |

### 6.2 品质 `tier`（Tab 可补全）

| 参数 | 含义 |
|---|---|
| `wood` | 木（代码有档，当前创造栏可能未出售） |
| `stone` | 石 |
| `copper` | 铜 |
| `iron` | 铁 |
| `gold` | 金 |
| `diamond` | 钻石 |
| `netherite` | 下界合金 |

大小写不敏感（内部按大写枚举解析）。

### 6.3 字段 `field`

| 字段 id | 含义 |
|---|---|
| `impulse` | 触发推进时的初速度冲量 |
| `thrustPerTick` | 持续推进阶段每 tick 追加推力 |
| `thrustTicks` | 持续推进 tick 数（会四舍五入为整数） |

大致距离量级（经验）：`d ≈ impulse * 11 + Σ(thrust)`，实际受空气阻力影响。

### 6.4 示例

```mcfunction
/boostermod balance show
/boostermod balance show iron
/boostermod balance set iron impulse 1.2
/boostermod balance set diamond thrustTicks 14
/boostermod balance reset gold
/boostermod balance reset
/boostermod balance reload
```

### 6.5 配置文件

路径：`config/boostermod-booster-balance.json`  

可手改 JSON 后执行 `/boostermod balance reload`，或只用命令改（`set`/`reset` 会自动 `save`）。
