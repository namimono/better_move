## 技巧化推进玩法（暂未决定，待选）

现在的推进核心玩法还是不够，暂时不想增加升级项等能力，简单粗暴地让玩家就可以推进得更远更快，希望实现一些"玩家通过特殊操作技巧让人物跳得更远更快"的玩法。

参考：
- 蔚蓝 Celeste：本身只是简单的冲刺跳跃，但延伸出 hyperdash / wavedash / demondash 等大跳玩法。
- 双人成行 It Takes Two：通过特定操作组合让跳跃飞得更远。

两个例子都没有升级项，而是靠**操作组合**让人物跳得更远更快。

### 设计原则

1. 不增加配置/属性：`BoosterTier` 字段保持不动，技巧只改变"一次推进的运行轨迹"。
2. 0 学习成本就能用，100 学习成本才精通：菜鸟按 Z 也能正常飞；高手通过 timing/输入组合飞得更远。
3. 失败有惩罚：技巧没成功不应该"没事发生"，最好是"还不如不按"——这样玩家会有"我刚才差一点点"的钩子。
4. 可量化反馈：练成必须对应肉眼可见的距离差。

### 候选技巧

#### A. 起跳推进 Hyper（来自 Celeste）

- **操作**：贴地按 Z 起飞前 ≤3 tick 内按过空格，判定为"起跳推进"。
- **效果**：当次推进 `impulse +25%`，起跳后的 Y 速度从 `0.42` 改为 `0.55`，Y 锁延后 2 tick 才生效，形成"先爆冲再悬停"的小弧度。
- **实现成本**：低。`BoosterMotionTicker.start()` 里读 `player.jumping`，或客户端起飞包里多带一个 `wasJumping` 标志位。
- **距离差**：约 +2 ~ +3 格。
- **失败惩罚**：无（按普通起飞处理）。
- **定位**：入门技巧，性价比最高，建议第一个做。

#### B. 链接推进 Chain Boost（思路源自 Celeste dash-into-dash）

- **操作**：第一次推进的**最后 3 tick 内**再次按 Z，触发"无缝衔接推进"。
- **效果**：第二次推进**不重置当前水平速度**（普通 `start()` 是 `setDeltaMovement` 强行覆盖；链接版是 `add` 而非 `set`），等于把上一次飞到末尾的残余水平速度作为基础叠加。
- **实现成本**：中。`ActiveBoost` 暴露剩余 tick 数；`start()` 增加"叠加模式"分支。
- **距离差**：完美衔接 ≈ +40% 总距离（接得早 = 没等空气阻力把速度磨光）。
- **失败惩罚**：**有惩罚**——在第一次推进还有很多 tick 时按 Z，要么没效果，要么按"立即开始下一段"判定（速度被覆盖）。判定窗口 3 tick = 0.15 秒，落在"看得见练得出"的甜蜜区。
- **定位**：真正的深度来源，可练习数日的核心机制。

#### C. 高空起跳 Fall Cancel（思路源自蔚蓝的反向冲）

- **操作**：在自由下落且 `deltaMovement.y < -0.6` 时按 Z。
- **效果**：把当前下落速度的 50% 折算进水平推进，`bonusImpulse = -deltaMovement.y * 0.5`。下落 1.2 → 多 0.6 水平冲量（约 +6 格距离）。
- **实现成本**：低。`applyBoost()` 起飞前读 Y 速度，传给 `BoosterMotionTicker.start()`。
- **距离差**：和起跳点高度成正比，鼓励"爬高再推进"。
- **失败惩罚**：地面起跳 = 0 加成（无负面）。

#### D. 撞墙反弹 Wall Reflect（自创）

- **操作**：推进期间撞墙的瞬间按 Z（误差 ≤ 3 tick）。
- **效果**：当前 `horizontalCollision = true` 这一帧不立即结束推进，而是把水平速度沿撞击面**反射**（取墙的法向量），剩余 `thrustTicks` 继续按反射方向推。
- **实现成本**：中等。需要读取碰撞面的法向（`player.horizontalCollision` 只是 bool，得用 `EntityCollisionContext` 或近期碰撞历史推算）；`BoosterLeggingsItem` 现有 collision 检测可参考。
- **距离差**：把"撞墙等于结束"变成"撞墙等于变向"，开 parkour 跑酷玩法。
- **失败惩罚**：没在窗口内按 → 按现在的逻辑结束推进。
- **定位**：门槛偏高，建议靠后做。

#### E. 反向爆冲 Counter Boost（简单趣味）

- **操作**：起飞瞬间客户端按住了**视角反方向**的移动键（朝北看但按 S）。
- **效果**：触发"后撤步推进"——`impulse +20%`，方向是玩家身后；同时给小垂直速度形成"后空翻"式起飞。视觉爽点拉满。
- **实现成本**：极低。客户端 `intendedBoost*Dir` 已经在算这个，加个标志位发上来即可。
- **距离差**：+1 ~ +2 格。
- **失败惩罚**：无。
- **定位**：偏视觉/趣味，深度增益一般。

#### F. 完美降落 Perfect Landing（与现有 60 tick 冷却互动）

- **操作**：推进结束**前 ≤3 tick**内贴到地面（`player.onGround()` 判定），且未撞墙。
- **效果**：本次推进的冷却 `60 → 25` tick。鼓励"贴地飞"，技术好的玩家约 1 秒就能再次推进。
- **实现成本**：低。`ActiveBoost.step()` 监测最后几 tick 的 `onGround()` 状态，结束时回调改 cooldown。
- **距离差**：单次没差，但**推进密度**翻倍 → 长距离移动总时间大幅缩短。
- **失败惩罚**：等满 3 秒冷却。

### 推荐组合

如果只挑 2 个先做（性价比 + 互不冲突 + 上手梯度合理）：

1. **A. 起跳推进 Hyper** — 玩家学到的"第一个技巧"，门槛低、奖励明显、改动小。
2. **B. 链接推进 Chain Boost** — 真正的深度来源。和 A 可叠加：起跳推进 → 末段衔接链接推进 → 持续滑翔。

加上现有的 WASD 微调，这套组合已经能涌现"起跳 → 爆冲 → 中途左拐 → 末段衔接 → 再爆冲"的连招，非常蔚蓝。

C / D / F 作为后续迭代。E 不太推荐——主要是噱头，不增加深度。
