# 推进器升级系统
玩家手持推进器时，按下使用键，进入推进器升级界面。升级界面根据不同等级的装备，可升级的槽位数量不同。

## 升级项
每个升级项可以放入升级槽位，就会触发对应的效果。升级项根据种类和效果不同，所需可合成的东西也不同，也就是说每个升级项都是一件新的物品。



## 升级项

### 冷却时间
1. 冷却时间重置


2. 冷却时间减少


### 空中冲刺
玩家默认在空中无法推进，需要一个能力来让玩家在空中推进。

### 推进带伤害
推进器在推进时，会对玩家周围的生物造成伤害。

### 推进后可无视摔落伤害
由于玩家可能在空中推进，所以需要一个能力来让玩家在推进后无视摔落伤害。
